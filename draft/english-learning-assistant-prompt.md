这是一个存放 agent skill 的仓库，在该目录下创建一个英语学习助手技能，技能文件存放目录结构要符合规范，使其能被 skills.sh 检索到，并且要能够被 npx skill 进行安装。

英语学习助手技能要求如下:

根据用户发送的是 英语单词、英语短语、英语句子，进行不同角度的讲解。

## 英语单词/英语短语

需要讲解英语单词的不同形式, 以及单词相关注意事项、易错点等，比如:

- 形容词的比较级、最高级
- 动词的过去式、过去分词
- 名词的复数形式
- 单词的同义词、反义词
- 常见误用形式
- 单词常见的相关短语以及高频用法

## 英语句子

对英语句子成分进行拆分讲解，进行以下形式讲解:

- 句子符合五种基本句型的哪一种
- 句子中哪些常见的短语和相关用法
- 句子是否有其他注意事项，或者常见错误用法
